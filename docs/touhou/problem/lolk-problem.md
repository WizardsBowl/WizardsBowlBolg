# 绀珠传运行问题记录 & 解决方法

绀珠传好难啊...

## 全屏后画面没有缩放也不居中

### 现象

- 以 1280 x 960 分辨率全屏启动游戏，启动后游戏画面未经任何缩放直接紧贴在屏幕左上角显示（不居中），屏幕有且只有右侧和下侧出现黑边（屏幕分辨率 1920 x 1080）。
  ![th15-resolution-error-mark](https://img.wizardsbowl.com/2026/08/th15-resolution-error-mark-e40bac93d46c79b1e29fcd33d10f5464.png)
- 该问题是在今年（2026）三月份左右某次系统更新（Windows 11 家庭版）之后才出现的，先前游戏画面在全屏时可以正常缩放和居中显示。
- 即使在启动选项中选择 1280 x 960 分辨率，游戏的运行日志中依然显示启动分辨率为 1920 x 1080 （按理来说游戏本来是没有这个分辨率的）。

  ```text{4}
  東方動作記録 --------------------------------------------- 
  使えるパッドが存在しないようです、残念
  DirectInput は正常に初期化されました
  解像度 1920 1080で起動します
  D3DFMT_A8R8G8B8 をサポートしていません、減色モードで動作します
  DirectSound は正常に初期化されました
  ---------------------------------------------------------- 
  ```
  
- 辉针城会与绀珠传同时出现此问题，当问题不再出现时也是同时的，不确定是否有其他作也有同样的问题。

### 不成功的尝试

- 更改英伟达控制面板中的“调整桌面尺寸和位置”有关选项（所有选项都不起效）。
- 切换使用独显与核显。
- 调整程序的兼容性选项（所有选项都不起效）。
- 修复DirectX运行库。
- 修复C++运行库。
- 使用VsyncPatch。

### 解决方法

- 在英伟达控制面板中更改桌面分辨率为 1280 x 960 之后再运行一次游戏，关闭游戏之后改回 1920 x 1080。
- 正常全屏运行一次红魔乡（红魔乡全屏运行时也会改变屏幕分辨率）。

我不确定以上两步中的哪一步解决了此问题，不过之后即使在默认屏幕分辨率 1920 x 1080 的情况下，全屏运行绀珠传时也可以成功自动切换为正确的屏幕分辨率，并将游戏画面显示在屏幕正中央。（我觉得是成功全屏运行红魔乡这一步起了效果!!「纯粹的玄学方法」!!）

当然，自从“解决”这个问题之后，我再也复现不了这个问题了。

除此之外，一通操作之后，虽然画面正常居中了，但是运行日志中多了一条提示“刷新率不是60Hz”。

```text{4}
東方動作記録 --------------------------------------------- 
使えるパッドが存在しないようです、残念
DirectInput は正常に初期化されました
リフレッシュレートが60Hzではありません
解像度 1280 960で起動します
D3DFMT_A8R8G8B8 をサポートしていません、減色モードで動作します
DirectSound は正常に初期化されました
---------------------------------------------------------- 
```

暂且不知道这一条是何意味，没注意过出问题之前是不是也有这一条。然而，我的系统设置中屏幕刷新率是60Hz，游戏内显示的fps也是60，所以我也没有深究。

### 替代方案

其实对于老游戏全屏缩放不正确的问题，也有一些可能的通用方案：

- ~~放弃全屏，投奔窗口化模式~~。
- 运行游戏之前手动更改屏幕分辨率，退出游戏之后再手动改回来。
- 使用Reso一类的工具自动在运行游戏时更改屏幕分辨率。
- 使用[Magpie](https://github.com/Blinue/Magpie)等窗口超分辨率工具，将窗口化游戏画面缩放到全屏大小。
- 调整显卡控制面板中的缩放设置。
- 调整程序的兼容性设置。
- 修复DirectX运行库。
